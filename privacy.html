Podcast Player privacy policy

Last updated 23 October 2026.

Podcast Player is a personal program that runs on its owner's own Windows computer. It has one user, its owner, and is not offered to anyone else.

What it uses from Google

When its owner signs in with Google, the program asks for permission to manage his YouTube account. It uses that permission for one thing only: to like or dislike a video when he presses the key for it, and to read back the rating he gave. It does not upload, delete, comment, subscribe, or read anything else from the account.

What it keeps

The sign-in token Google returns is stored on the owner's computer, encrypted so that only his Windows account can read it. Nothing is sent to anyone other than Google and YouTube, nothing is shared, sold, or used for advertising, and there is no server belonging to this program anywhere.

Withdrawing permission

Permission can be withdrawn at any time from the Google Account's security settings, under third-party connections, at myaccount.google.com/connections.

YouTube and Google

This program uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
